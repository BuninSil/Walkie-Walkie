# Walkie-Walkie

Рация по мотивам Quansheng UV-K5: каналы PMR446/LPD, VOX, ROGER, двойное прослушивание, шифрование.

| Папка | Что это |
|---|---|
| [`radio-walkie`](radio-walkie/README.md) | Рация для ПК (Windows, Electron) — со своим сервером эфира (пункт 14 HOST) |
| [`android`](android/README.md) | Та же рация для Android — подключается к серверу эфира ПК-рации |

Обе рации говорят на одном протоколе и слышат друг друга: откройте HOST на ПК и введите его адрес
на телефоне в **MENU → 12 SERVER**.
