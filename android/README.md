# Рация для Android

Та же рация, что и на ПК (`../radio-walkie`), только на телефоне. Код рации не дублируется:
при сборке берётся прямо из `radio-walkie/web`, поэтому кнопки, меню, каналы, шифрование и протокол
у них одинаковые. Телефон подключается к **серверу эфира** — например, к тому, что открыт в
ПК-рации пунктом **14 HOST**.

## Как подключить телефон к ПК

1. На ПК: **MENU → 14 HOST → ON**. Рация покажет адрес для друзей.
2. Телефон и ПК в одной Wi-Fi сети → берите **локальный** адрес ПК, например `192.168.1.10:8765`
   (узнать: `ipconfig` на ПК, строка «IPv4-адрес»). Телефон через мобильный интернет → нужен внешний
   адрес, который HOST показывает, если роутер открыл порт по UPnP.
3. На телефоне: включите рацию (щелчок по ручке), **MENU → 12 SERVER → MENU → MENU («НОВЫЙ…»)**,
   наберите адрес на клавиатуре телефона, **Enter**. Появится **NET** — связь есть.
4. Тот же канал, что на ПК, и говорите, удерживая **PTT** сбоку. При первой передаче Android спросит
   доступ к микрофону.

Адрес запоминается, при следующем запуске рация подключится сама (пункт **13 AUTO**).

Если **NET** не загорается: проверьте, что на ПК включён HOST, и что Windows пустила «Рацию» в сеть
(брандмауэр при первом запуске HOST спрашивает — нужно разрешить для **частных** сетей). Гостевая
Wi-Fi сеть роутера часто не пускает устройства друг к другу.

> ПК-рация до этой версии не пускала приложение с телефона (проверка Origin в `air-server.js`).
> На ПК нужна рация из этого репозитория — или любой сервер эфира, который принимает
> Origin `http://localhost`.

## Что отличается от ПК

- Нет своего сервера (HOST), «поверх окон» и полоски для игр — это про ПК.
- Рация работает в фоне: свернули или выключили экран — приём продолжается, в шторке висит
  уведомление «Рация — на приёме». Кнопка «Назад» сворачивает рацию, а не закрывает. Закрыть —
  смахнуть из недавних приложений.
- Текст (позывной, адрес, ключ SCR) набирается на экранной клавиатуре.

## Сборка

**Готовый APK** собирает GitHub Actions (workflow «Android APK») при каждом пуше —
скачайте `walkie-android-apk` на странице запуска, распакуйте и установите `app-debug.apk`
(Android попросит разрешить установку из неизвестных источников).

**Сами** — нужны Node.js 22, JDK 21 и Android SDK (проще всего через Android Studio):

```bash
npm install
npm run apk        # собрать www/ из ../radio-walkie/web, синхронизировать и собрать debug APK
npm run open       # или открыть проект в Android Studio
```

APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`.
После правок в `radio-walkie/web` или `mobile/` выполните `npm run sync`.

## Устройство

| Файл | Что это |
|---|---|
| `scripts/build-web.js` | Собирает `www/` из `../radio-walkie/web` + `mobile/` |
| `mobile/mobile.js` | Мост: включает пункты SERVER/AUTO, растягивает рацию на экран |
| `mobile/mobile.css` | Фон, центровка, отключение выделения и жестов браузера |
| `capacitor.config.json` | Страница открывается с `http://localhost`: микрофон работает, `ws://` к ПК разрешён |
| `android/app/src/main/java/ru/radio/walkie/MainActivity.java` | «Назад» сворачивает, запуск фонового сервиса |
| `android/app/src/main/java/ru/radio/walkie/WalkieService.java` | Фоновый приём: уведомление, WakeLock, WifiLock |
