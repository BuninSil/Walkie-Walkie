# Рация для Android

Это рация с ПК (`../radio-walkie`) как есть: в APK кладётся `radio-walkie/web` без единой правки —
та же страница, те же скрипты, то же меню, тот же протокол. Android-часть только заменяет
оболочку Electron:

| ПК (Electron) | Android |
|---|---|
| `preload.js` → `window.radioDesktop` | `assets/android/bridge.js` → тот же `window.radioDesktop` |
| страница с `app://radio` | страница из APK, WebSocket — из Java с тем же `Origin: app://radio` |
| окно 300×528 | рация растянута на экран телефона (`assets/android/android.css`) |

Для сервера эфира телефон ничем не отличается от ПК-рации, поэтому подключается к тем же серверам.

## Подключение

1. Включите рацию (щелчок по ручке).
2. **MENU → 1 → 2** (пункт 12 SERVER) → **MENU** («НОВЫЙ…») → **MENU**.
3. В окне «Адрес сервера» наберите адрес так же, как на ПК (например `203.0.113.5:8765`
   или `radio.example.ru`), **Готово**.
4. Загорится **NET** — связь есть. Тот же канал, что у собеседников, и держите **PTT**.
   При первой передаче Android спросит доступ к микрофону.

**Мобильный интернет:** к серверу эфира сейчас подключается только через **VPN с иностранным
сервером** — без него операторы соединение не пропускают (Android пишет «Software caused connection
abort»). На Wi-Fi всё работает без VPN.

Если связи нет, внизу экрана появится сообщение Android с причиной: «порт закрыт или сервер
выключен», «сервер не отвечает», «адрес не найден», «сервер отказал (403)»…

## Что есть только на телефоне

- **Ввод текста** (позывной, адрес сервера, ключ SCR) — окном Android с нормальной клавиатурой.
- **Настройки** — шестерёнка над рацией: кнопка PTT поверх приложений, «не гасить экран», обновления.
- **Фонарик** — боковая кнопка ☼ включает и настоящий фонарик телефона.
- **Внешний вид** — ⚙ → «Внешний вид и темы»: 10 расцветок в родном стиле рации; корпус (цвет,
  фактура, ручка, светодиоды, антенна); кнопки (цвет, цифры, F-надписи, вибрация); экран (6 стилей,
  подсветка, 11 готовых фонов и своя картинка, узоры, мягкое свечение); фон за рацией (свой цвет или
  картинка); шрифты экрана и кнопок; «Сбросить» — вид по умолчанию.
- **Кнопка PTT поверх приложений**: держите — говорите, короткий тап — открыть рацию, потащите —
  переставить. Кольцо: серое — на связи, зелёное — приём, красное — передача, оранжевое — нет связи.
  Нажатия приходят в рацию так же, как горячая клавиша на ПК.
- **Постоянное уведомление**: на связи ли рация, канал, кто говорит; кнопки «Кнопка PTT поверх» и
  «Выключить». «Назад» и «свернуть» рацию не выключают — приём продолжается.

- **Микрофон — только на время передачи**: через 1,5 с после PTT рация его отпускает. Пока микрофон
  открыт, Android держит телефон в режиме звонка и не переключает звук на наушники — ни у рации, ни
  у других приложений. С включённым VOX микрофон открыт всё время (так нужно для VOX).

Нет на телефоне: **14 HOST** (свой сервер), **15 TOP**, полоска поверх игр, горячие клавиши.

## Обновления и подпись

Каждая сборка подписывается одним и тем же ключом и получает номер версии больше предыдущей,
поэтому новый APK ставится **поверх** — настройки, сервер и позывной сохраняются.

Ключ хранится в секретах репозитория (Settings → Secrets and variables → Actions):

| Секрет | Что это |
|---|---|
| `WALKIE_KEYSTORE_BASE64` | файл ключа `walkie-release.p12` в base64 |
| `WALKIE_KEYSTORE_PASSWORD` | пароль ключа |

Без секретов сборка проверяет код, но APK не выпускает. **Ключ не терять и не выкладывать:** без него
обновить установленную рацию нельзя, с ним кто угодно может выпустить «обновление».

## Сборка

APK собирает GitHub Actions (workflow «Android APK»): артефакт `walkie-android-apk` → `Walkie-1.0.N.apk`.

Сами: JDK 17+ и Android SDK (проще — Android Studio, открыть папку `android`), затем

```bash
WALKIE_KEYSTORE_FILE=walkie-release.p12 WALKIE_KEYSTORE_PASSWORD=... ./gradlew assembleRelease
```

Файлы рации копируются из `../radio-walkie/web` при каждой сборке.

## Файлы

| Файл | Что это |
|---|---|
| `app/src/main/java/ru/radio/walkie/MainActivity.java` | WebView с рацией, микрофон, «Назад», свернуть/закрыть |
| `app/src/main/java/ru/radio/walkie/AirSocket.java` | WebSocket к серверу эфира из Java (OkHttp), Origin как у ПК |
| `app/src/main/java/ru/radio/walkie/WalkieService.java` | Приём в фоне, постоянное уведомление, WakeLock, WifiLock |
| `app/src/main/java/ru/radio/walkie/PttBubble.java` | Кнопка PTT поверх других приложений |
| `app/src/main/java/ru/radio/walkie/AirState.java` | Что в эфире (связь, приём, передача, канал) — для уведомления и кнопки |
| `app/src/main/assets/android/bridge.js` | `window.radioDesktop` вместо `preload.js`, WebSocket через Java, ввод текста, настройки |
| `app/src/main/assets/android/android.css` | Рация на экране телефона, панель настроек |
| `app/src/main/assets/android/look.js`, `look.css` | Внешний вид: темы, корпус, кнопки, экран, фоны, шрифты |
| `app/src/main/assets/android/fonts/` | Шрифты для экрана и кнопок (OFL) |
